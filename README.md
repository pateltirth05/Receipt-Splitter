# 🧾 Receipt Splitter

A lightweight and practical web app that helps users quickly split a bill among multiple people, including tip calculation.

## 🚀 Features

* Enter total bill amount
* Add number of people
* Include tip percentage
* Automatically calculates:

  * Total amount with tip
  * Per-person share
* Real-time updates as you type

## 🛠 Tech Stack

* HTML
* CSS
* JavaScript (Vanilla)

## 🎯 Purpose

This project focuses on building a clean and functional UI while handling real-time calculations and user input validation. It demonstrates core JavaScript concepts like DOM manipulation, event handling, and basic arithmetic logic.

## 📌 Future Improvements

* Add support for uneven bill splitting
* Include names for each person
* Rounding options for easier payments
* Save previous entries using localStorage

## 💡 Why This Project?

Splitting bills is a common real-world problem. This app aims to provide a simple and efficient solution with a clean user experience.
